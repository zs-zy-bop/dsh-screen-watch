# dsh-screen-watch

让 DSH 里的伴侣陪你刷抖音：**只截目标窗口的画面**，按"一条视频一组"自动分组，画面直接送进模型，你们可以就着同一条片子聊。

## 它解决什么

现在的 AI 陪你看视频，多半只能"截一帧问一句"。这个插件做的是另一件事：

- 只截你指定的那个窗口（抖音桌面版），别的窗口盖在上面也挡不住
- 不碰播放：暂停、拖动、切视频都由你自己来
- 自己判断"这一条是不是同一条视频"，按条归组，而不是按分钟切
- 把整条视频的帧拼成带时间戳的拼版图，一次送进模型
- 带一个「陪刷抖音」设置面板：状态、最近几条、缩略图

## 判断"是不是同一条视频"的办法

按可靠程度依次使用：

1. **总时长 + 进度**：左下角那条 `02:08 / 04:34`，总时长变了几乎必然是换了片子；进度往回跳说明重播或换条
2. **右侧互动数字**：点赞、评论、收藏、转发在同一格视频里不变，换片才变（不读数字，直接给那块区域算指纹）
3. **标题/作者**：OCR 读底部那行字，只当辅助
4. **画面相似度**：仅作最弱的参考——同一条片子里换镜头也会变得面目全非

为了避免误切，换片要"连读两次都一致"才成立；不足 3 帧的误切会自动并回上一条。

## 安装

要求：Windows 10/11、DSH ≥ 0.2.0-rc.2。

DSH 插件通过 npm 分发，装好之后：

```
dsh plugin --profile <你的 profile> add dsh-screen-watch
```

桌面版的 profile 由 Electron 托管，命令行有时走不通，那就用本包里附带的 `install-local.mjs` 把包挂进 profile，然后整个退出 DSH 再开。

## 从 GitHub 安装

仓库：https://github.com/zs-zy-bop/dsh-screen-watch

插件市场里可以用 GitHub 源装，安装时会锁到具体 commit：

`
dsh plugin --profile <你的 profile> add "github:zs-zy-bop/dsh-screen-watch#v0.3.1"
`

装完要整个退出 DSH 再开一次，插件和面板才会加载。

## 用法

在对话里说一句"开始看"，或者打开 设置 → 陪刷抖音 点"开始"，之后正常刷抖音就行。

想看某一条的完整画面，跟它说"把刚才那条从头铺开"，它会生成带时间戳的拼版图；哪一段没看清，也可以只要那一段。

参数（也可以在工具里直接传）：

- 进程名，默认 `douyin`
- 截图间隔，默认 1000 毫秒
- 最多保留几条视频，默认 5 条，第 6 条进来时删最旧那条

## 声音（可选，默认不开）

装了 Python 3 和 `pyaudiowpatch`、`faster-whisper`、`numpy` 之后，可以开声音层：录系统输出（整机声音，不是某个程序），本地转写，不上传。

模型从 `small` 起步；`large-v3-turbo` 更准但更慢。纯音乐、没人声的段落容易冒出"请不吝点赞、订阅、转发"这类模型自编的句子，插件会把这类短句丢掉。

## 隐私

- 只截你指定进程的窗口
- 帧存在 `%USERPROFILE%\.dsh\screen-watch\<进程名>\videos\`，只保留最近几条
- 声音层只在本机转写，音频不出机器

## 已知不足

- 只支持 Windows
- 个别硬件加速的应用 `PrintWindow` 会返回全黑，目前不回退
- 抖音桌面版没有对外接口，标题只能靠 OCR 读，字压在画面上时会有错字
- 视频很长（>20 分钟）时拼版图会分成多页，需要分段看
